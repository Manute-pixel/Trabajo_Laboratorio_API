# Poncho Digital API

API REST desarrollada para el proyecto **Poncho Digital**, una plataforma digital destinada a brindar informacion y gestionar los datos relacionados con los artesanos, productos y stands de la Fiesta Nacional e Internacional del Poncho.

## Requisitos

* Node.js 24.x LTS
* npm

## Instalacion

Para instalar las dependencias del proyecto, ejecutar:

npm install

## Ejecucion

Para iniciar el servidor en modo desarrollo, ejecutar:

npm run dev
